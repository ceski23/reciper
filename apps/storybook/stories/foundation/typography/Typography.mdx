## Typography

The typography system provides a comprehensive set of text styles for consistent typographic hierarchy across the application. Each style variant is carefully designed to work together to create visual balance and readability.

### Available Styles

The typography system includes the following style categories:

- **Display** (Large, Medium, Small) - For prominent headlines and attention-grabbing text
- **Headline** (Large, Medium, Small) - For section headers and major content divisions
- **Title** (Large, Medium, Small) - For subsection titles and card headers
- **Body** (Large, Medium, Small) - For body text and main content paragraphs
- **Label** (Large, Medium, Small) - For labels, buttons, and small UI text
